# Module 01 — Premiers pas

🟢 Débutant | ⏱ 3 h (cours 1 h, exercices 1 h 30, fil rouge 30 min) | 🔑 print, commentaires, variables, types, opérations, round

Ta première ligne de Python, puis tes premiers calculs : afficher un message, ranger des valeurs sous un nom,
calculer un écart de température et convertir des degrés Celsius en degrés Fahrenheit.

## Objectifs

À la fin de ce module, tu sauras :

1. **Afficher** un texte ou un nombre avec `print`, et **commenter** ton code avec `#`.
2. **Ranger** une valeur dans une variable, la **réutiliser** et la **modifier**.
3. **Reconnaître** les quatre types de base (`int`, `float`, `str`, `bool`) avec `type()`.
4. **Calculer** avec `+ - * / // % **` en respectant la priorité des opérations, et **arrondir** avec `round`.
5. **Lire** une `NameError` et une `SyntaxError`, et les corriger.
