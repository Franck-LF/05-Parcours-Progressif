# Module 05 — Les listes, ta colonne Excel

⏱ Durée estimée : 4 h (cours 1 h 20, exercices 2 h, fil rouge 40 min)

## Objectifs

À la fin de ce module, tu sauras :

- **ranger** plusieurs valeurs dans une liste, et **lire** un élément par sa position ;
- **modifier** une liste : ajouter, insérer, retirer un élément ;
- **parcourir** une liste avec `for` (et `enumerate` pour avoir le numéro) ;
- **résumer** une liste avec `len`, `sum`, `min`, `max`, et la **trier** ;
- **fabriquer** une nouvelle liste à partir d'une autre, avec une boucle puis avec une compréhension de liste.

## Prérequis

- Modules à avoir faits : 00 à 04.
- Tu dois savoir faire : une boucle `for` sur un `range`, un accumulateur (`total = total + x`), un compteur,
  un record (`if valeur > record`), une tranche de chaîne (`texte[0:3]`), `.split()`, `float()`, une f-string.

## Je sais faire

- [ ] Je crée une liste entre crochets, et une liste vide `[]`.
- [ ] Je lis le premier élément avec `[0]` et le dernier avec `[-1]`.
- [ ] Je prends un morceau de liste avec une tranche `[debut:fin]`.
- [ ] J'ajoute à la fin avec `.append()`, j'insère avec `.insert()`, je retire avec `.remove()` ou `.pop()`.
- [ ] Je teste la présence d'une valeur avec `in`.
- [ ] Je parcours une liste avec `for`, et avec `enumerate` quand j'ai besoin du numéro.
- [ ] Je calcule une moyenne avec `sum(liste) / len(liste)`, et je trouve le `min` et le `max`.
- [ ] Je trie avec `sorted()` (nouvelle liste) ou `.sort()` (la liste elle-même).
- [ ] Je transforme une chaîne `"12.0;13.5"` en liste de nombres.
- [ ] J'écris une compréhension de liste, avec ou sans `if`, et je sais l'écrire aussi en boucle.
